SETUP TIME (t_su)

The minimum time interval the data input signal ($D$ or $S/R$) must remain stable BEFORE the active clock transition edge.

HOLD TIME (t_h)

The minimum time interval the data input signal must remain stable AFTER the active clock transition edge.

CLOCK-TO-Q DELAY (t_cq)

The propagation delay time taken from the triggering edge of the clock signal until output $Q$ reaches its final valid logic level.

Master-Slave Architecture & Race-Around Prevention

Class Foundation: Eliminating level-sensitive output oscillations during prolonged active clock pulses

How Master-Slave Works:

1. When CLK = 1: The Master stage is active and samples inputs, while the Slave stage is isolated.

2. When CLK = 0: The Master stage locks, and the Slave stage activates, passing the Master's output to $Q$.

This two-stage isolation ensures output $Q$ can only change state once per clock cycle, preventing continuous toggling race conditions!

Flip-Flop Family Overview

SR FLIP-FLOP

Set / Reset

Fundamental memory element. Sets $Q=1$ or Resets $Q=0$. Has invalid $S=1, R=1$ condition in basic gates.

D FLIP-FLOP

Data / Delay

Eliminates invalid states by connecting $R = \bar{S}$. Output $Q$ follows input $D$ on clock edge.

JK FLIP-FLOP

Universal / Toggle

Solves invalid SR state. When $J=1, K=1$, the output toggles state ($Q_{next} = \bar{Q}$).

T FLIP-FLOP

Toggle / Divider

Single input $T$. When $T=1$, output toggles on every clock edge. Widely used for frequency division.

Logic Conventions Summary

  • NAND SR Latch: Active-Low inputs ($S', R'$ or $\bar{S}, \bar{R}$). Set condition occurs when $S'=0, R'=1$ ($Q=1$). Invalid state occurs when $S'=0, R'=0$.
  • NOR SR Latch: Active-High inputs ($S, R$). Set condition occurs when $S=1, R=0$ ($Q=1$). Invalid state occurs when $S=1, R=1$.
  • 4-to-2 Encoder: $Y_1 = D_2 + D_3$, $Y_0 = D_1 + D_3$. Standard mode requires single active line; Priority mode enforces $D_3 > D_2 > D_1 > D_0$.
